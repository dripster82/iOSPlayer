# Design assets

`icon-candidates/` holds five app icon concepts generated on 24 Oct 2026 with Paul's OpenAI Codex CLI
(image generation), at Paul's direction, in the app's palette (amber #F0A33A on charcoal #0E0E10).
Paul chose **icon3_letter_r** (the letter R formed from a film strip); it is installed as
`Reel/Resources/Assets.xcassets/AppIcon.appiconset/AppIcon.png` (1024×1024, no alpha — iOS derives
every other size from it). The outputs are Paul's under OpenAI's terms; they are generated art, not
hand-drawn or stock.
